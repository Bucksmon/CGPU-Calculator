# Gradepoint — GPA Calculator

A lightweight, responsive semester GPA calculator for four university grading systems:

- Capital University of Science & Technology (CUST)
- COMSATS University
- Air University
- Bahria University

## Features

- Switch between university-specific grade scales.
- Add and remove courses.
- Select credit hours and letter grades for each course.
- Calculate credit-weighted GPA instantly.
- View total credit hours, total grade points, and the selected grading reference.
- Responsive layout with animated result ring and reduced-motion support.
- No framework, build step, account, or server required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Deploy

This is a static website. The repository root is the publish directory and does not need a build command.

For GitHub Pages: open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Notes

The grade values are carried forward from the original project data. University policies can change, so users should confirm the active grading policy with their institution.
